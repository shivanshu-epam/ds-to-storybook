# Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| `The token cannot open file … (HTTP 403/404)` | Wrong link, or the token's account cannot view the file | Check the link. Create the token from an account with access. |
| `Variables API unavailable (HTTP 403)` | The Variables REST API is Enterprise-only | Export variables with the ds-sync Figma plugin and set `generate.variablesExport`. Without it, values stay raw. |
| `HTTP 429`, then waiting | Figma rate limits (Tier 1: 10–20 requests a minute) | ds-sync waits and retries, and caches responses in `.ds-sync/cache`. Use `--refresh` only when Figma has changed. |
| A component looks empty or misplaced | A layer type the generic template approximates (vector shapes, image fills, instance swaps) | See the component's "Generation notes" on its docs page and in `GENERATION-REPORT.md`. |
| axe `color-contrast` failure | The design's colours are below WCAG thresholds | Raise it with design. Record it in `overrides.knownIssues` only with agreement. |
| axe `button-name` or `landmark-unique` | A missing accessible name in the design or the sample copy | Report it. It usually needs a Figma or template change. |
| `… exists and was not generated by ds-sync` | `init` refuses to overwrite a folder it did not create | Choose another folder with `--dir`. |
| Stories show old content | The dev server watched files while they were being regenerated | Restart `npm run storybook`. |
