<h2>{"Accessibility"}</h2>
<p style={{ whiteSpace: 'pre-line' }}>{"A button triggers an immediate action, such as submit, confirm, open or delete."}</p>
<h3>{"What the design system provides"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A Focused state on every variant, with a 3px ring bound to border/interactive/focus."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A Disabled state on every variant."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Label typography bound to all five label text-style tokens for each size."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Minimum heights of 32, 40 and 48px — all above the 24×24px target-size minimum (WCAG 2.5.8)."}</p>
<h3>{"Development considerations"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Use a native <button> element. Default to type=\"button\" to avoid accidental form submits; use submit or reset only when intended."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Disabled: use the disabled attribute or aria-disabled=\"true\". Disabled buttons must block clicks, keypresses and focus-triggered actions."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Icon-only buttons need an accessible name via aria-label."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Decorative icons get aria-hidden=\"true\"."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   While loading, block repeat activation until the action resolves."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Never convey state through color alone."}</p>
