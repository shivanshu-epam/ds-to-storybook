<h2>{"Accessibility"}</h2>
<p style={{ whiteSpace: 'pre-line' }}>{"A dialog is a focused window layered over the page that blocks interaction until a task or decision is resolved."}</p>
<h3>{"What the design system provides"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A close icon on every type, alongside Escape."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Footer actions are real Buttons, with their focus and disabled states."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A Loading state that disables the footer buttons to prevent double submits."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A Form Error state with a text error banner, not color alone."}</p>
<h3>{"Development considerations"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Use role=\"dialog\" with aria-modal=\"true\" and aria-labelledby pointing to the title."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Trap focus inside the dialog; return focus to the trigger on close."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Exclude background content from the accessibility tree while a decision is required — not just dim it."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   The close icon is icon-only — give it an accessible name."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Set initial focus on the first field, or the primary button when there's no form."}</p>
