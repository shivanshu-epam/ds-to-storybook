<h3>{"What the design system provides"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A Focused state with a 3px ring on NavControl."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A Disabled NavControl state for the edges of finite carousels."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   An AutoplayToggle with Playing and Paused states, so autoplay can always be stopped."}</p>
<h3>{"Development considerations"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Wrap the slides in a live region (aria-live=\"polite\"), turned off during autoplay, so slide changes are announced."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Make off-screen slides inert so they can't be reached by Tab."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Don't move focus when the slide changes unless the user triggered it by keyboard."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Pagination dots must be reachable and operable by keyboard."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Prev, Next, pause and dot controls are icon-only — each needs an accessible name."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Pause autoplay on hover, focus-within and a hidden tab; stop it after any interaction."}</p>
