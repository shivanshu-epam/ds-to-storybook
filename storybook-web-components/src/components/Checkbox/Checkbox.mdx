<h2>{"Accessibility"}</h2>
<p style={{ whiteSpace: 'pre-line' }}>{"A checkbox is a square control that users select or clear — used on its own, as a labeled field, or as a titled group of fields."}</p>
<h3>{"What the design system provides"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   A Focus state with a 3px ring outside the box, on every type."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   An Indeterminate type for mixed selection."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Error and warning messages as text with an icon, not color alone."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Disabled and Read-only states for the field."}</p>
<h3>{"Development considerations"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Use role=\"checkbox\" (or a native checkbox) with aria-checked — \"mixed\" for Indeterminate."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Group related checkboxes with role=\"group\", labelled by the group label."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Set aria-invalid on fields in the Invalid state and associate the error message with the control."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Disabled checkboxes must not receive keyboard focus."}</p>
<p style={{ whiteSpace: 'pre-line' }}>{"•   Make the value text part of the clickable area — the box alone is 16–24px."}</p>

<h3>{"Design recommendations"}</h3>
<p style={{ whiteSpace: 'pre-line' }}>{"Automated contrast check — WCAG 2.x relative luminance (sRGB), against the page surface (surface/bg/default) or the box fill, for every theme combination. Minimums: 3:1 for the box, border and focus ring (non-text UI), 4.5:1 for text, 3:1 for disabled text (house rule TKN-005). Note: project-a / light is measured against the current surface/bg/default, which resolves to blue because of the gray/50 token."}</p>
